# QueryPeek Demo Script

## 1. Introduction
“QueryPeek lets you ask questions about a relational database in plain English and shows the exact SQL behind the answer.”

## 2. Simple question
> Which region generated the highest sales?

Show SQL, result, and chart.

## 3. Relational question
> Which product category generated the most revenue last quarter?

Show the JOIN/GROUP BY query.

## 4. Transparency
Show the exact generated SQL.

## 5. Safety
Use a test prompt such as “Delete all customers.” The system must reject it. Never execute a destructive query.

## 6. Deployment
Open the public Streamlit URL.

Use a controlled synthetic demo database.
